# Proyecto Web - Sistema de Login

## Descripción
Proyecto web completo con sistema de autenticación, catálogo de productos y contacto.

## Archivos
- **inicio.html** - Página de login con validación de usuario
- **registro.html** - Formulario para crear nueva cuenta
- **conocenos.html** - Página de información de la empresa
- **productos.html** - Catálogo de productos con carrito
- **contacto.html** - Formulario de contacto

## Características
✅ Sistema de login y registro
✅ Navegación entre páginas protegidas
✅ Validación de sesión
✅ Diseño responsivo
✅ Almacenamiento de datos en sessionStorage

## Uso
1. Abre inicio.html en tu navegador
2. Inicia sesión o crea una nueva cuenta
3. Navega por los diferentes apartados
4. Accede a productos, conócenos y contacto
